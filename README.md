# TechEdge Institute Portal

A full-stack student portal built using Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

- Student Registration and Login
- JWT Authentication
- Student and Admin Roles
- Course Management
- Batch Management
- Offer Management
- Student Enrollment
- Enrollment Approval and Rejection
- Online Exams
- Exam Autosave and Submission
- Server-side Exam Scoring
- Exam Results
- Placement Management
- Company Management
- Student Feedback
- Admin Management
- Swagger API Documentation
- Postman API Collection

## Technology Stack

### Backend
- Java 17+
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- MySQL
- Maven

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript
- Fetch API

### Tools
- IntelliJ IDEA
- MySQL Workbench
- Postman
- Git
- GitHub
